| No | Komponen RPP/MA | Indikator Yang Diamati | Skor (1-4) | Catatan |

| **1** | **Identitas RPP/MA** | **Lengkap:** Mata pelajaran, jenjang, kelas, materi pokok, alokasi waktu, dll. | | |
| **2** | **Identifikasi Murid** *(Opsional)* | **Terdapat:** Identifikasi kesiapan murid sebelum belajar, seperti pengetahuan awal, minat, latar belakang, dan kebutuhan belajar, serta aspek lainnya. | | |
| **3** | **Materi Pembelajaran** *(Opsional)* | **Jelas:** Jenis pengetahuan yang akan dicapai, relevansi dengan kehidupan nyata, struktur materi, tingkat kesulitan, integrasi nilai karakter, dsb. | | |
| **4** | **Dimensi Profil Lulusan** | Terdapat Dimensi Profil Lulusan yang ditentukan selaras dengan tujuan pembelajaran dan kegiatan yang dilakukan. | | |
| **5** | **Capaian Pembelajaran** *(Opsional)* | Terdapat rumusan yang jelas, spesifik, dengan kata kerja operasional dan sesuai dengan Capaian Pembelajaran pada CP BSKAP. | | |
| **6** | **Lintas Disiplin Ilmu** *(Opsional)* | Terdapat keterkaitan disiplin ilmu dan/atau mata pelajaran yang relevan dengan tujuan pembelajaran. | | |
| **7** | **Tujuan Pembelajaran** | • Mencakup kompetensi dan konten pada ruang lingkup materi dengan menggunakan kata kerja operasional yang relevan.<br>• Tujuan pembelajaran, langkah pembelajaran, dan asesmen pembelajaran sudah mengarah pada pencapaian Dimensi Profil Lulusan.<br>• Tujuan pembelajaran, langkah pembelajaran, dan asesmen pembelajaran sudah selaras. | | |
| **8** | **Topik Pembelajaran** *(Opsional)* | Terdapat topik pembelajaran yang relevan dengan capaian dan tujuan pembelajaran. | | |
| **9** | **Praktek Pedagogis** | • Praktik pedagogis yang dituliskan sudah tergambar pada langkah pembelajaran dan/atau asesmen pembelajaran.<br>• Tergambarkan kesesuaian model, pendekatan, strategi, metode, atau teknik pada kegiatan pembelajaran. | | |
| **10** | **Kemitraan Pembelajaran** *(Opsional)* | Kemitraan pembelajaran yang dituliskan sudah tergambar pada langkah pembelajaran dan/atau asesmen pembelajaran. | | |
| **11** | **Lingkungan Pembelajaran** | Lingkungan belajar yang dituliskan sudah tergambar pada langkah pembelajaran dan/atau asesmen pembelajaran. | | |
| **12** | **Pemanfaatan Digital** *(Opsional)* | Pemanfaatan digital yang dituliskan sudah tergambar pada langkah pembelajaran dan/atau asesmen pembelajaran. | | |
| **13** | **Kegiatan Awal** | • Kegiatan awal yang dituliskan meliputi orientasi yang bermakna, apersepsi yang kontekstual, dan motivasi yang menggembirakan.<br>• Memuat prinsip pembelajaran mendalam berupa berkesadaran, bermakna, dan/atau menggembirakan yang tergambar pada setiap pengalaman belajar.<br>• Perencanaan pembelajaran sudah mengakomodir pengalaman belajar sesuai karakteristik murid. | | |
| **14** | **Kegiatan Inti** | • Langkah pembelajaran dapat memfasilitasi murid untuk merasakan **pengalaman belajar MEMAHAMI** (mengkonstruksi pengetahuan, menghubungkan pengetahuan baru dengan yang lama, mengaitkan konteks nyata, memberi ruang eksplorasi & kolaborasi, menanamkan nilai moral & karakter).<br>• Langkah pembelajaran dapat memfasilitasi murid untuk merasakan **pengalaman belajar MENGAPLIKASI** (menghubungkan konsep baru, menerapkan dalam situasi nyata, eksplorasi lanjut, berpikir kritis & mencari solusi inovatif).<br>• Langkah pembelajaran dapat memfasilitasi murid untuk merasakan **pengalaman belajar MEREFLEKSI** (evaluasi diri, regulasi emosi, motivasi belajar, strategi berpikir, metakognisi). | | |
| **15** | **Kegiatan Akhir** | Langkah pembelajaran dapat memfasilitasi tindakan saling **MEMULIAKAN** antara guru-murid, murid-guru, dan murid-murid (verbal maupun nonverbal). | | |
| **16** | **Asesmen Awal** | Asesmen awal pembelajaran dilaksanakan untuk mengetahui kesiapan belajar (emosi, mental, pengetahuan awal, kebutuhan belajar). | | |
| **17** | **Asesmen Proses** | Asesmen selama proses pembelajaran dilaksanakan sesuai rencana untuk memantau perkembangan, memberi umpan balik, dengan beragam teknik. | | |
| **18** | **Asesmen Akhir** | Asesmen hasil pembelajaran direncanakan untuk mengukur pencapaian kompetensi dengan berbagai cara (tes, portofolio, proyek, presentasi, dsb.). | | |
| **19** | **Rubrik Penilaian** | Terdapat kriteria ketercapaian tujuan pembelajaran dari masing-masing tujuan pembelajaran yang akan dinilai. | | |
| **20** | **Lembar Kerja Murid (LKM)** | Lembar kerja murid selaras dengan tujuan pembelajaran dan kegiatan pembelajaran. | | |
